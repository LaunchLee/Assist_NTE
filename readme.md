目前只做了店长特供1-1自动化、抚摸动物自动化、钓鱼自动化。

安装 [AutoIt](https://www.autoitscript.com/site/)，下载本项目，
解压并运行 Game_NTE.au3 即可使用。

由于个人设备问题，游戏分辨率使用 1280x720，脚本相关视觉资源均基于此分分辨率。
虽然脚本有自动伸缩适配检测机制以适配不同分辨率，但未测试过。
End 键确实指 End 键。

## 关于游戏

### 异环

劳动最光荣。

基于 Maa 框架的自动化比较占用资源，但有些操作实在太重复了，就用传统的自动化
（决定性决策）解决这些操作吧。

## 关于脚本

这个脚本只做简单的、具有强烈视觉重复规律的自动化。
其他详情看这个[基本项目](https://github.com/LaunchLee/Assist_MuvLuv)。
